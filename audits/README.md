# Reviewed audits

Each folder holds the audits of one project release, one `audit.json` per data flow, the rendered report, and the record of a second review. Layout: `audits/<project>/<version>/`.

An audit rates one release, platform, sync mode, and data flow from static reading of the pinned source. Check the review record before relying on a rating.
